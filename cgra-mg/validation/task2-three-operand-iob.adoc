== Structural contract

`tram.common.IobMode.numOperands` is the single mode contract: FIFO is 1, SRAM is 2, and conditional load/store is 3. Both `IobParam` implementations, the shared `IOB`, and `IOController` use it. `IOB` also rejects a `num_input_per_operand` list whose logical length disagrees with the mode.

The active conditional MultiTile generation produced this unique IOB structure:

[cols="2,1",options="header"]
|===
|Field |Value

|`iob_mode`
|2

|`num_operands`
|3

|physical `num_input`
|6, two selectable inputs per logical operand

|IOB instances
|one `IOController`, one three-lane `DelayPipe`, three `Muxn`

|controller configuration
|bits 0--126, unchanged from SRAM; no `UseEn`

|delay configuration
|bits 127--138

|mux configuration
|bits 139, 140, 141

|aggregate configuration
|bits 0--141, continuous and non-overlapping apart from the aggregate `This` range
|===

Structured tests prove each logical operand's two external candidates reach its own mux, then delay lane 0/1/2, then `IOController` input 0/1/2. They also prove every top-level conditional IOB receives all six physical inputs from GIB connections. No interconnect implementation change was required because the active single-tile and MultiTile wiring already derives pin counts from `num_input_per_operand`.

The optimized standalone `IOController` Verilog retains `io_in_2` without a `dontTouch` annotation, so no preservation workaround was added.

== Predicate interface decision

Task 2 locks the routed predicate representation to word bit 0, without consuming it in store hardware yet.

Evidence:

* ADORA's `ADORA.cond_store` condition is an `i1`.
* VITRA integer comparison operations produce one-bit UInt results which are zero-extended on the uniform-width ALU output.
* VITRA `SEL` explicitly selects on `op2(0)`.
* The focused ALU test proves EQ produces word values 0/1 and SEL treats operand values 1, 0, and 2 as true, false, and false respectively. This distinguishes bit 0 from a non-zero interpretation.

Task 3 may use this documented bit only when it adds `UseEn` and write gating. Task 2 does not read `io.in(2)` in `wValid`, `realEn`, `sram.en`, or `sram.we`.

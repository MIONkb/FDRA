=== Write permission and legacy behavior

The controller keeps scheduling and side-effect permission separate:

[source,text]
----
writeRequest = wValid && (wRealValid || useAddr)
writeAllowed = !useEn || io.in(2)(0)
writeIssue   = writeRequest && writeAllowed
----

For conditional mode, `writeIssue` controls both SRAM `en` and `we`. For FIFO/SRAM modes, the legacy `wValid` write-mask behavior and address/data capture conditions are retained. Reads use their independent request path and never consume operand 2.

The predicate true rule is word bit 0. Predicate words 0 and 2 are false; word 1 is true. This matches the Task 2 ALU/SEL evidence and is explicitly distinguished from a non-zero interpretation.

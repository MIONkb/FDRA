= Task 2 full-CGRA external-configuration runtime

== Outcome

Task 2 uses the vendored-minimum runtime model.  The auditable runtime is in
`cgra-mg/e2e/cstore`; it instantiates an unmodified, fresh-generated
`CGRAWithAXI` beneath the simulation-only `CStoreTraceWrapper`.  The wrapper
only renames the generated AXI ports and exports all 48 physical SRAM request,
write-mask, address, and data paths.  It does not implement CSTORE behavior.

The external input is the ADORA Mapper's existing `config.bit` format.  The
adapter preserves packet order and deterministically packs each hexadecimal
`address data` pair as three little-endian 16-bit words: data low, data high,
then address.  Placement and configuration bits are never reconstructed in
the cocotb test.

== Fresh production command

[source,shell]
----
scripts/run-adora-cstore-e2e.sh \
  --config /home/jyhu/adora-compiler-scheduletasks-h/test/cgra-mapper/cstore_contract/Output/mapped_routes.mlir.tmp/cstore-seed-7/cstore_route_map_result/config.bit \
  --case cgra-mg/e2e/cstore/smoke-case.json \
  --result /tmp/vitra-task2-production/smoke-result.json \
  --trace /tmp/vitra-task2-production/smoke-trace.json \
  --work-dir /tmp/vitra-task2-production \
  --chipyard-root /tmp/vitra-cstore-closeout-chipyard.xiZnMy \
  --sbt-cache-root /tmp/vitra-cstore-closeout-sbt
----

The runner first proves that the isolated Chipyard FDRA source is byte-for-byte
identical to this checkout, then runs `tram.vitra.CStoreVerilogGen` in a fresh
directory.  It consumes and hashes all six same-generation artifacts, adapts
the external config, compiles the 615-module core, configures it through real
AXI/AXI-Lite transactions, observes busy-to-done, and writes a physical SRAM
trace.  Missing result or trace files are a nonzero failure.

== Verification result

The fresh full-CGRA smoke passed with simulation exit code 0.  Configuration
became idle within the bounded 516-cycle window, execution produced a real
busy-to-done transition (`done_cycle=3`), and the machine-readable trace
contained seven physical SRAM request events.  This smoke establishes runtime
loading, compilation, start/done, and observability; Task 3 supplies the
CSTORE true/false/normal-STORE behavioral oracle.

Five focused Python tests pass.  They cover valid packet parsing/packing,
malformed/duplicate/out-of-range rejection, same-generation hash enforcement,
FOR/CLOAD rejection, complete 48-bank wrapper observability, and the complete
machine-readable interface.  `py_compile`, `bash -n`, interface regeneration,
and `git diff --check` also pass.

The ADORA checkout remained read-only at its baseline: tracked `.gitignore`
was already modified, `TODO-cstore-mapper-adora.md` was already untracked, and
the Git index remained clean.  Task 2 made no ADORA changes.
